# Create-ClearGoal

一个 Create 附属模组，为自动化产线提供三件实用工具：

- **配方过滤器**：把配方装进过滤槽，让机器按你记录的配方工作。
- **大宗工厂仪表**：原版工厂仪表的高量程版本。
- **产品返回站**：将网络承诺的产品打包发回指定地址。

---

## 安装

- Minecraft **1.21.1**
- NeoForge **21.1.x**
- Create **6.0.10 / 6.0.11**

把 `createcleargoal-*.jar` 放入 `mods` 文件夹即可。

---

## 配方过滤器

放入 Create **工作盆**或**动力锯**的过滤槽使用。

- 手持过滤器右键打开编辑界面，最多记录 **9 条配方**
- 支持从 JEI / EMI / REI 导入配方（含流体输入/输出）
- 三种模式：
  - **阻止记录配方**（Block）
  - **只允许记录配方**（Allow-only）
  - **按输入锁定**（Lock on input）：输入匹配记录配方时只做该配方，其他输入不受影响
- 产物匹配支持**精确**与**包含**
- 可嵌套在列表过滤器中

## 大宗工厂仪表

与原版工厂仪表行为一致，但目标数量支持更大的量程。

## 产品返回站

必须贴在打包机上使用。

- 使用前先像工厂仪表一样调谐网络频率
- GUI 可设置：
  - 原料输入端地址
  - 产品输出端地址
  - 承诺过期时间
- 输入地址**默认使用 Create 地址匹配**；以 `regex:`（不区分大小写）开头时使用 **Java 正则**，必须匹配整个地址，并启用输出捕获组 `$1` / `${name}`
- 只处理放置后新产生的承诺，不追溯历史承诺
- 多个站共享同一网络、同一输入地址且同一红石优先级时，接收承诺的选择未定义
- 红石信号越强优先级越低（`0` 最高、`15` 最低）
- 打包机空闲时会把多个承诺合并进一个包裹
- 承诺在包裹真正被送出后才算完成

---

## 兼容性

- 大宗工厂仪表与原版工厂仪表共用物流网络，可混放、可互连
- 产品返回站使用独立承诺队列，不影响 Create 原版承诺系统
- 内置简体中文与英文
