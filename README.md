# Create-ClearGoal

---

一个 Create 附属模组，为模块化、自动化产线提供新工具

- **配方过滤器**：把“配方”装进过滤槽，让机器按你记录的配方工作。
- **大宗工厂仪表**：原版工厂仪表的高量程版本。
- **产品返回站**：将网络承诺的产品打包发回指定地址。

---

## 功能一览

### 配方过滤器（Recipe Filter）

放入 Create 工作盆或动力锯的过滤槽，即可按记录的配方限制机器选择。

- 手持过滤器右键打开编辑界面，最多记录 9 条配方
- 3×3 输入槽 + 3 输出槽，支持从 JEI / EMI / REI 导入
- 三种过滤模式：
  - 阻止记录配方（Block）
  - 只允许记录配方（Allow-only）
  - 按输入锁定（Lock on input）：输入匹配记录配方时只进行该配方，对其他输入不做筛选
- 两种产物匹配：精确匹配 / 包含匹配
- 可嵌套在列表过滤器中使用

### 大宗工厂仪表（Bulk Factory Gauge）

与原版工厂仪表的行为一致，区别在于可以接受更大的目标数量。

###  产品返回站（Product Return Station）

必须贴在打包机上使用，让打包机进入“返回阶段”。

- 使用前需先像工厂仪表一样调谐网络频率
- GUI 设置：
  - 原料输入端地址：接收哪些地址发来的承诺
  - 产品输出端地址：打包后发往哪里
  - 承诺过期时间
- 使用独立承诺队列，只统计放置后且地址匹配的承诺；输入地址支持完整正则与捕获组，输出地址可用 `$1` / `${name}` 填充捕获内容
- 当某两个站在同一网络中，接受同一原料地址，处于同一红石优先级时，这两个站接收承诺的选择是未定义而不可知的
- 红石信号强度信号越强优先级越低（`0` 最高、`15` 最低）
- 打包机空闲时，可能把多个承诺/多种产品合并进一个包裹
- 承诺在包裹真正被送出后才算完成

---

## 兼容性

- **大宗工厂仪表**与原版工厂仪表共用物流网络，可混放、可互连
- **产品返回站**使用独立承诺队列，不影响 Create 原版承诺系统
- 手动填槽只支持物品；从 JEI / EMI / REI 导入的配方会保留流体输入/输出
- 内置简体中文与英文
