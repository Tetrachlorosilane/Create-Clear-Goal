# Create-ClearGoal

一个面向 Create 玩家的附属模组，为加工机械、物流与工厂仪表补充三件实用工具：

- **配方过滤器**：把“配方”装进过滤槽，让机器按你记录的配方工作。
- **大宗工厂仪表**：原版工厂仪表的 4 行高量程版本。
- **产品返回站**：让打包机进入“返回阶段”，自动把网络承诺的产品打包发回指定地址。

---

## 功能一览

### 🧪 配方过滤器（Recipe Filter）

放入 Create **工作盆**（辊压机、动力搅拌器）或**动力锯**的过滤槽，即可按记录的配方限制机器选择：

- 手持过滤器右键打开编辑界面，最多记录 **9 条配方**
- 3×3 输入槽 + 3 输出槽，支持从 **JEI / EMI / REI** 拖拽或一键导入
- 三种过滤模式：
  - **阻止记录配方**（Block）
  - **只允许记录配方**（Allow-only）
  - **按输入锁定**（Lock on input，默认）：输入命中记录配方时只做该配方；否则按原逻辑
- 两种产物匹配：**精确匹配** / **包含匹配**
- 连续加工时，装/移/编辑过滤器会在**本批结束后立即生效**
- 可嵌套在 Create **列表过滤器**中使用

### 📊 大宗工厂仪表（Bulk Factory Gauge）

原版工厂仪表的行为完全一致（仓储监控、打包机补货、物流网络、红石输出、显示链接、扳手交互），区别在目标数量：

- 长按右键的滑动条从原版 2 行扩展为 **4 行，全部按“组”**：
  - `0–32` 组：线性
  - `32–256` 组：64 / 128 分段
  - `256–2048` 组：512 / 1024 分段
  - `2048–16384` 组：4096 / 8192 分段
- 组数按物品自身最大堆叠换算（需求 = 组数 × maxStackSize）
- 与原版工厂仪表可混用、可互相连接

### 📦 产品返回站（Product Return Station）

贴在**打包机**上，让打包机进入“返回阶段”（黄色状态条）：

- 使用前需先像工厂仪表一样**调谐网络频率**
- GUI 设置：
  - **原料输入端地址**：接收哪些地址发来的承诺
  - **产品输出端地址**：打包后发往哪里
  - **承诺过期时间**：`-1` 永不过期、`0` 为 30 秒、`1~31` 为 N 分钟
- 使用独立承诺队列，只统计放置后且地址匹配的承诺；**输入地址支持完整正则与捕获组**，输出地址可用 `$1` / `${name}` 填充捕获内容
- **同一网络 + 同一原料地址 + 同一红石优先级**：仅当某个站存在“同地址且同优先级”的其它站时才提示该站冲突，不强制禁用；同优先级的站接收承诺的选择是未定义而不可知的
- 冲突提示使用 Create 的**工程师护目镜悬浮框**（佩戴护目镜看向返回站时显示）
- **红石信号强度 = 优先级**：信号越强优先级越低（`0` 最高、`15` 最低）；收到红石信号时方块切换为 powered 贴图
- 打包机空闲时，可把多个承诺/多种产品**合并进一个包裹**（不超过单个包裹容量）
- 承诺在包裹真正被送出后才算完成

## 安装

- Minecraft **1.21.1**
- NeoForge **21.1.x**（Java 21）
- Create **6.0.10 / 6.0.11**
- JEI / EMI / REI（可选，任一安装即可获得配方导入与拖拽）

把 `createcleargoal-*.jar` 放入 `mods` 目录即可。

## 快速上手

### 配方过滤器

1. 获得配方过滤器（创造标签页 / 配方合成）
2. 手持右键打开编辑界面
3. 从 JEI / EMI / REI 拖拽物品，或在配方界面点击导入
4. 选择过滤模式与匹配方式
5. 放入工作盆或动力锯的过滤槽
6. 机器按记录配方工作；输入不匹配时恢复原逻辑

### 大宗工厂仪表

1. 手持**仓储链接站**右键已有网络调谐
2. 放置大宗工厂仪表
3. 长按右键打开 4 行滑动条设置目标数量

### 产品返回站

1. 手持**产品返回站**右键已有网络调谐
2. 贴在打包机上
3. 右键打开 GUI，设置输入/输出地址与承诺过期时间
4. （可选）用红石信号设置优先级：信号越强优先级越低
5. 工厂仪表创建承诺后，返回站会自动检查打包机容器并打包发送

## 合成配方

| 物品 | 配方 |
|---|---|
| 配方过滤器 | 红石粉 + 工作台 + 红石粉（一行） |
| 大宗工厂仪表 | 工厂仪表 + 磨制玫瑰石英（无序） |

产品返回站目前通过创造标签页获取（暂无合成配方）。

---

## 兼容性

- **大宗工厂仪表**与原版工厂仪表共用物流网络，可混放、可互连
- **产品返回站**使用独立承诺队列，不影响 Create 原版承诺系统
- 手动填槽只支持物品；从 JEI / EMI / REI 导入的配方会保留流体输入/输出
- 内置简体中文与英文
